# 🚀 Real Estate Intelligence Platform - Live Deployment Guide

This guide provides step-by-step instructions to deploy the entire project (FastAPI Backend + Streamlit Frontend) live to production on **Render**, **Railway**, **Streamlit Cloud**, or **Docker/VPS**.

---

## Option 1: Deploy on Render (Recommended - Free Tier Available)

### Option 1A: Automatic Blueprint Deployment (Easiest)
1. Push your repository to **GitHub** or **GitLab**.
2. Log into [Render Dashboard](https://dashboard.render.com/).
3. Click **New +** -> **Blueprint**.
4. Connect your repository. Render will automatically detect `render.yaml` and create both services:
   - `real-estate-backend` (FastAPI)
   - `real-estate-frontend` (Streamlit)
5. Click **Apply**. Both services will build and launch automatically!

### Option 1B: Manual Service Setup on Render
#### Step 1: Deploy FastAPI Backend
1. Go to Render Dashboard -> **New +** -> **Web Service**.
2. Connect your GitHub repository.
3. Set the configuration:
   - **Name**: `real-estate-backend`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
4. Click **Create Web Service**.
5. Copy the backend URL generated by Render (e.g. `https://real-estate-backend.onrender.com`).

#### Step 2: Deploy Streamlit Frontend
1. Go to Render Dashboard -> **New +** -> **Web Service**.
2. Connect your GitHub repository.
3. Set the configuration:
   - **Name**: `real-estate-frontend`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `streamlit run Home.py --server.port $PORT --server.address 0.0.0.0`
4. In **Environment Variables**, add:
   - `API_URL` = `https://real-estate-backend.onrender.com` (Your backend URL from Step 1)
5. Click **Create Web Service**.

## Option 2: Deploy on Railway

1. Log into [Railway.app](https://railway.app/).
2. Click **New Project** -> **Deploy from GitHub repo**.
3. Select your repository.
4. Add service 1 (Backend):
   - Set start command: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
   - Generate domain (e.g. `backend-production.up.railway.app`)
5. Add service 2 (Frontend):
   - Set start command: `streamlit run Home.py --server.port $PORT --server.address 0.0.0.0`
   - Set environment variable `API_URL` to your backend Railway domain URL.

## Option 3: Unified Docker Container Deployment (Single Web Service)

If you prefer to run both backend and frontend inside a **single container service** (saving hosting costs):

```bash
# Build unified Docker image locally
docker build -t real-estate-app .

# Run locally on port 8501
docker run -p 8501:8501 -p 8000:8000 real-estate-app
```

You can deploy `Dockerfile` directly to **Hugging Face Spaces** (Docker space), **Render** (Docker Web Service), or **Fly.io**.

---

## Option 4: Local / VPS Docker Compose Deployment

To run multi-container deployment locally or on any cloud server (AWS, DigitalOcean, Hetzner, GCP):

```bash
# Start backend & frontend containers
docker-compose up -d --build

# View container status
docker-compose ps

# Stop services
docker-compose down
```

## 🛠️ Environment Variables Reference

| Variable Name | Default Value | Description |
|---|---|---|
| `API_URL` | `http://127.0.0.1:8000` | Full URL of the deployed FastAPI backend endpoint |
| `BACKEND_URL` | `http://127.0.0.1:8000` | Alternative fallback URL for backend |
| `PORT` | `8501` / `8000` | Dynamic port provided by cloud provider |
